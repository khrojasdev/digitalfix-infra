# docs

| Documento | Qué contiene |
|---|---|
| `modelo-datos.md` | Modelo de datos completo del sistema, tabla por tabla, con tipos, restricciones e índices, y el porqué de cada decisión. |
| `diagrama-modelo-datos.md` | Los mismos esquemas como diagramas entidad-relación. |
| `arquitectura.md` | Componentes, flujo de una petición y despliegue. |
| `matriz-funcionalidades.md` | Funcionalidades del sistema y su estado por microservicio. |
| `matriz-pruebas.md` | Pruebas automatizadas: qué verifica cada una, tipo, evidencia y resultado. |
| `flujos-de-prueba.md` | Plan de pruebas manuales de punta a punta: flujos por rol, pasos, resultado esperado y hallazgos conocidos. |

Los diagramas están en Mermaid dentro del Markdown, no como imágenes: así se
versionan en texto y el diff muestra qué cambió. GitHub los renderiza solo.
